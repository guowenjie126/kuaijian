# 云端接口状态

验证时间：2026-10-21（本机环境）

本次客户端验证产物：`/Applications/快剪重建版.app`，构建脚本为 `build-native.sh`。

## 已确认存在

- `GET /health`：返回 `kuaijian-api` 健康状态。
- `POST /v1/auth/register/send-code`：短信注册验证码入口。
- `POST /v1/auth/login/send-code`：短信登录验证码入口。
- `POST /v1/auth/register`：手机号、密码、`smsCode` 注册入口。
- `POST /v1/auth/login`：手机号、密码，可附带 `smsCode` 登录入口。
- `GET /v1/clipboard`：需要 Bearer 登录令牌，客户端已接入“同步云端”读取。

客户端已完成：

- 登录/注册页和设置 → 账号页均可输入手机号、密码、短信验证码。
- “获取验证码”按登录/注册分别调用对应短信接口。
- 登录成功后保存云端访问令牌；剪贴板页的“同步云端”会读取并合并云端文本/网址。

- `/v1/devices/register`、`/v1/transfers` 当前没有可用的正式服务端路由证据。
- 连接、互传、问答云端表结构和写入接口没有在当前工作区提供，不能仅凭客户端猜字段后直接写生产数据库。
- 当前工作区和用户目录中没有找到 `kuaijian-server` 服务端源码、数据库迁移或部署配置，因此暂时不能安全地新增生产表、修改公网 API 或执行数据库迁移。

4. 由管理员提供的部署入口；不要把数据库密码、短信密钥或 Token 写入源码。

客户端已经先把短信认证和现有剪贴板接口接好；拿到服务端源码和表结构后，再补迁移、鉴权、数据同步和两台设备验收。
