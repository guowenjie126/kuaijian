# 快剪原生版重建工程

这是从当前安装版行为和本机用户数据目录重建的 macOS 原生源码工程。原始旧源码目录已不在磁盘上，因此这里不声称是旧源码的逐字恢复，而是保留 Bundle ID、数据格式和主要交互后的新实现。

## 构建

```sh
cd "/Users/guowenjie/Desktop/快速复制/快剪原生版"
./build-native.sh
open "build/快剪重建版.app"
```

构建产物为 `build/快剪重建版.app`，使用现有 Bundle ID `com.kuaijian.native`，本地数据继续使用：

`~/Library/Application Support/KuaiJianNative`

## 当前已接入

- 剪贴板监听、文本/网址/图片分类、搜索、收藏、删除、点击复制反馈。
- 问答精确/模糊匹配、别名和关键词、CSV/JSON 导入、CSV 导出、答案自动复制。
- 问答助手全局剪贴板触发，不要求问答页面一直打开。
- 翻译页面的剪贴板读取、自动识别方向的基础本地词典翻译和复制译文。
- 系统区域截图快捷键 `⌘⇧4`，直接调用 macOS 自带截图，不重复申请录屏权限。
- 计算器、快捷入口、应用选择、链接打开、快捷键文本保存。
- 设置、权限入口、账号云端登录请求和更新入口。

## 兼容边界

- 现阶段是 macOS 重建版；Windows 版本没有在本工程内实现。
- 已接入当前安装包内的 Sparkle 框架和原更新源；正式对外发布仍需要 Developer ID 签名、公证和服务器上的签名更新包。
- 团队、设备连接、互传的本地页面已保留入口；真实云端同步、局域网直连和断点续传仍需按服务端协议继续接入。
- `build-native.sh` 当前使用本机 Swift 编译器和临时签名，不能替代 Apple Developer Developer ID 签名。
